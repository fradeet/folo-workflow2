# Alfred Folo

![][show1]

An Alfred workflow backed by the official [Folo CLI][].

## Requirements

- Alfred 5 and the Powerpack
- Node.js 24 or later
- A Folo account

## Usage

For usage instructions, see [workflow/README.md][].

## Development

Install the `workflow` folder as an Alfred workflow using whichever method you prefer.

After editing `workflow/README.md`, run `<developing>` to copy it into
Alfred's `workflow/info.plist` metadata.
